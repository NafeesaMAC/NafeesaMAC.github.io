# Data

Put your exported Brag Book here as `brag-book.csv` for offline development. In the Brag Book sheet use the page's download option (CSV) for the Brag Book tab.

Expected columns (header names must match):
Project, Role, Period, Result, Problem, What I did, PM keywords, Numbers still to add, Impact type, Recruiter appeal, Why it attracts recruiters, Show on portfolio, Featured, Theme, Headline metric, Cover image link, Order

The last six (Show on portfolio, Featured, Theme, Headline metric, Cover image link, Order) are added in Google Sheets. The live site uses the Apps Script URL, not this file. Do not commit private columns if the repo is public: `Numbers still to add` and `Why it attracts recruiters` are for you only.

Suggested starting point: tick Show on portfolio for Top and Strong rows, and Featured for 4 of the Top rows (for example the blood-draw agent, the vendor ecosystem, the pre-enrolment app and US partner launches).
